# Security & Privacy

## Зачем используются IP-адреса

PulseLine использует IP-адреса только для задач безопасности:

- журнал входов и регистраций;
- определение подозрительной активности;
- защита от brute force по IP;
- блокировка отдельных IP и CIDR-диапазонов;
- контроль и отзыв активных сессий.

## Что показывает геолокация

- Геолокация по IP является примерной.
- Обычно она позволяет определить страну, регион, город, ASN или провайдера.
- IP-геолокация не показывает точный домашний или офисный адрес пользователя.

## Ограничения точности

- VPN, proxy, Tor, NAT и мобильные сети могут подменять или искажать реальный IP.
- Даже без VPN IP может указывать на ближайший узел провайдера, а не на фактическое местоположение пользователя.
- Данные геолокации следует использовать как вспомогательный сигнал, а не как абсолютное доказательство местонахождения.

## Operational Notes

- Если `GEOIP_PROVIDER=none`, backend сохраняет IP без страны и города.
- Ошибки GeoIP lookup не должны ломать вход пользователя.
- IP из `ADMIN_IP_WHITELIST` не блокируются и не попадают под ограничение попыток входа.
